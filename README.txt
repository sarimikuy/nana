CARA PAKAI
1. Buat project:   composer create-project laravel/laravel profil-saya
2. Salin isi folder ini ke project (timpa routes/web.php), strukturnya sama.
3. Ubah nama di app/Http/Controllers/ProfilController.php  ($nama)
4. Ganti foto di public/images/galeri/ dan sesuaikan nama file di method galeri()
5. Jalankan:  php artisan serve   lalu buka http://127.0.0.1:8000
